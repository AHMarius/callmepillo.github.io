# Definitii

- Traseu
\\[ T = Traseu \\]

- Numar traseuri
\\[ NT_c = Numar\\;traseuri\\;complete \\]
\\[ NT_i = Numar\\;traseuri\\;incomplete \\]
\\[ NT_t = Numar\\;traseuri\\;totale \\]

- Timp
\\[ t(T) = Timpul\\;obtinut\\;pe\\;traseul\\;T \\]
\\[ [t(T)] = [s] \\]
\\[ t_i = Timpul\\;ideal = 60s \\]

- Precizia
\\[ P(s) = \frac{NTc(s)}{NTt(s)} \\]
\\[ P_i = Precizia\\;ideala = 1 \\]

- Eficienta
\\[ E(T) = \frac{t(T)}{t_i} \\]
\\[ E_M(s) = \frac{1}{N} \sum_{i=0}^N E(i) \\]
\\[ E_{M_i} = Eficienta\\;ideala = 1 \\]

- Target factor
\\[ f(s) = \frac{P(s) \cdot E_M(s)}{P_i \cdot E_{M_i}} \\]

- Target factor pentru \\( P_i = 1; E_{M_i} = 1 \\)
\\[ f(s) = P(s) \cdot E_M(s) \\]
